## Decision
Hearth is released under the **MIT** license.

## Notes
- HestiaCP is GPL-3.0, but Hearth does not include or link Hestia code — it only invokes Hestia's CLI on remote servers — so license compatibility is not an issue.
- Permissive license maximises adoption and contributions.
